API — PLANNED SHAPE

One key, both datasets

The API is in validation. This is the shape early-access members are voting on — endpoints and a real record from the current scan.

Endpoints

  • GET /v1/tcg/cards — all tracked cards, filter by set / min spread
  • GET /v1/tcg/cards/{id} — one card, full breakdown + sources
  • GET /v1/tcg/scans/latest — scan time, FX rate, coverage
  • GET /v1/jdm/models — market aggregates per model
  • GET /v1/jdm/models/{id} — one model, sources + eligibility notes
  • GET /v1/meta — FX, last update, source list
