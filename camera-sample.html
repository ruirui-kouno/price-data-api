Working or junk decides the price

The same Canon FD 50mm f/1.4 sold for ¥5,980 working and ¥4,280 for the same model — a 40% gap decided by one thing: whether anyone had checked that it works. Film cameras are only comparable on two axes at once: condition grade (S / A+ / A / B / C) and working state (working vs. junk). This sample shows eight models with Japan-side prices measured from public listings in September–November 2026. FX: ¥158.70 / $1.

How we compare — the grading axes

  • Condition grade: S / A+ / A / B / C — the grades Japan's major used-camera shops already standardise on.
  • Working state: working (operation confirmed) vs. junk (operation not guaranteed). A row never mixes the two.
  • Comparison rule: only the same model, the same grade and the same working state are ever compared. Rows of different grades or states are never shown as a “gap”.
  • Collection: manual snapshots of public listings. Mercari blocks bots, so Japan-side prices are hand-checked (same handling as TCG's Mercari source).
  • Export note: lithium batteries cannot go by international mail — battery-included vs. battery-free is recorded separately and battery cost is split out of shipping. Mechanical cameras have no voltage problem for export.

HOW WE COMPARE

Same model, same grade, same working state — or no row

Film camera prices swing with grade and working state, so a comparison is only valid on three axes at once.

  • Model: brand + model + mount must match exactly. Near matches are not compared.
  • Grade: S / A+ / A / B / C as listed. A “B” body is a different item from an “A” body of the same model.
  • Working state: working vs. junk, recorded separately and never mixed in the same table.
  • Sources: public retail and marketplace listings only. No member-only auction data, no scraped private marketplaces.
